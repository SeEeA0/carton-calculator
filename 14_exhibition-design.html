박람회 백월 디자인 및 국가별 언어

분할형 또는 전체형 백월 구조에 맞춰 디자인하고, 개최 국가의 언어 특성과 번역 검수 가능 여부에 따라 영어 또는 현지어를 적용합니다.

국가별 언어 선택

국가·지역언어 기준
영어권영어로 디자인
동남아 및 비영어권현지어 필요 여부를 확인하고 번역이 정확하게 준비된 경우 적용
현지어가 너무 어렵거나 검수가 어려운 경우영어를 중심으로 디자인하고 필요한 짧은 현지어만 확인 후 적용
현지어를 임의로 번역하거나 의미를 추측해서 사용하지 않습니다. 영업 담당자, 고객사 또는 현지 담당자가 확인한 문구를 사용합니다.

백월 기본 콘텐츠

  • 회사 또는 브랜드 로고
  • 메인 슬로건과 회사 강점
  • 대표 제품 이미지
  • OEM·ODM 서비스
  • 연구·생산·QC·디자인 역량
  • 연락처, 홈페이지 또는 QR 코드

부스에서 멀리서도 보이도록 문장을 줄이고 핵심 단어와 큰 제품 이미지를 중심으로 구성합니다.

분할형 백월 디자인 방법

  1. 전체 부스를 펼친 상태로 먼저 디자인합니다.
  2. 패널 번호와 실제 규격에 맞춰 아트보드를 나눕니다.
  3. 연결되는 배경과 이미지가 패널 사이에서 자연스럽게 이어지는지 확인합니다.
  4. 중요 문구와 로고는 패널 경계에서 떨어뜨립니다.
  5. 각 파일명에 패널 번호를 넣습니다.
EXHIBITION_NAME_PANEL_01.ai EXHIBITION_NAME_PANEL_02.ai EXHIBITION_NAME_PANEL_03.ai

전체형 백월 디자인 방법

  1. 전체 규격으로 아트보드를 생성합니다.
  2. 중앙과 시선 높이 기준선을 설정합니다.
  3. 로고, 메인 문구와 대표 제품을 우선 배치합니다.
  4. 상담대와 가구에 가려지는 하단에는 중요 내용을 넣지 않습니다.
  5. 출력업체가 분할 출력하는 경우 연결부를 확인합니다.

출력 파일 확인

  • 실제 출력 규격과 아트보드 규격
  • 축소 작업 비율과 해상도
  • CMYK 또는 업체 지정 컬러모드
  • 이미지 링크 포함 또는 임베드
  • 폰트 아웃라인
  • 재단 여유와 안전영역
  • 패널 번호와 좌우 방향

최종 검토

언어

영문 오탈자, 현지어 검수 여부, 공식 제품명과 회사명을 확인합니다.

현장

사람과 가구에 가려지는 부분, 조명, 패널 연결부, 로고 시인성을 확인합니다.
