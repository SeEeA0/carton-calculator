HTML·CSS 및 기능 수정 범위

Cafe24 기반 홈페이지에서 헤더, 메뉴, 문의 버튼, 검색, 게시판, 반응형 화면과 페이지별 HTML·CSS를 수정합니다. 서버나 결제처럼 직접 담당하지 않은 기능은 인수인계 범위에 포함하지 않습니다.

작업 전 백업

  • 수정할 언어몰과 페이지 경로 확인
  • 기존 HTML·CSS 전체 복사 또는 파일 백업
  • 공통 레이아웃인지 개별 페이지 코드인지 확인
  • 수정 전 화면 캡처
  • 같은 클래스가 다른 페이지에 영향을 주는지 확인

주요 코드 관리 업무

  • 헤더와 푸터 메뉴 구성
  • CONTACT, 검색, 제품·회사·박람회 메뉴 링크
  • 문의 게시판 작성 페이지 연결
  • 문의 완료 페이지와 다국어 경로
  • 연혁 타임라인, 공장 갤러리, 인증서 롤링
  • PC·태블릿·모바일 반응형 CSS
  • 이미지 경로와 텍스트 정렬

다국어 경로 관리 예시

몰문의 작성 경로 예시
한국어/board/product/write.html?board_no=6
영어/shop2/board/product/write.html?board_no=6
베트남어/shop3/board/free/write.html?board_no=6

실제 운영 중인 경로가 변경될 수 있으므로 관리자에서 최종 주소를 확인하고 적용합니다.

수정 후 테스트

화면

PC, 태블릿, 모바일에서 너비, 여백, 글자, 이미지 잘림과 스크롤을 확인합니다.

기능

메뉴 이동, CONTACT, 검색, 게시판 작성, 완료 화면, 파일 업로드와 버튼 동작을 확인합니다.

오류 발생 시 복구

수정 후 레이아웃이나 기능에 문제가 생기면 임의로 여러 부분을 계속 변경하지 말고, 백업 코드로 먼저 복구한 뒤 수정 범위를 좁혀 다시 작업합니다.
