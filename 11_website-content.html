홈페이지 운영 범위

홈페이지 관리 업무는 패키지 디자인과 별도 영역으로 기록합니다. 디자인팀에서는 제품·회사·박람회 콘텐츠를 등록하고 배너, 이미지, 문구, 메뉴와 링크가 정상적으로 보이는지 관리합니다.

다국어몰 구분

한국어몰

국문 회사·제품 정보, 문의 페이지, 검색과 게시판을 관리합니다.

영어몰

영문 메뉴와 제품명, 문의 경로, 이미지와 정렬을 확인합니다.

베트남어몰

베트남어 문구와 별도 몰 경로, 문의 완료 페이지를 확인합니다.

수정 전에 어느 언어몰을 수정하는지 확인하고, 공통 수정인지 해당 몰에만 적용할 내용인지 구분합니다.

콘텐츠 관리 업무

  • 메인 배너와 주요 이미지 교체
  • 제품 이미지·제품명·용량·설명 등록
  • 상세페이지 등록 및 교체
  • 회사소개, 연혁, 공장, 인증서 업데이트
  • 박람회 일정과 전시 정보 등록
  • 오탈자와 번역 문구 수정
  • 메뉴·버튼·이미지 링크 점검
  • 문의 게시판과 작성 페이지 확인

업데이트 진행 순서

수정 요청 확인 →대상 언어몰 확인 →기존 화면 캡처·백업 →이미지·문구 준비 →관리자 또는 코드에서 수정 →PC 확인 →모바일 확인 →링크·게시판 확인 →수정일 기록

이미지 등록 기준

  • PC와 모바일에서 잘리지 않는 비율 확인
  • 화질이 낮거나 지나치게 큰 파일은 최적화
  • 언어가 이미지 안에 들어간 경우 언어몰별 별도 이미지 사용
  • 파일명에 제품명·언어·용도를 표시
  • 이전 이미지와 최신 이미지가 섞이지 않도록 정리
