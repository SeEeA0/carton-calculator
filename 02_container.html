용기 선정 및 CT 테스트

제형에 적합한 용기를 선정하고 실제 충전량·누액·토출·부자재 구성을 확인한 뒤, 내용물 확정 후 CT 테스트를 준비합니다.

용기 선정 기본 원칙

먼저 고객사 또는 영업 담당자에게 원하는 용기 형태를 확인합니다. 이후 연구소에 해당 제형을 그 용기에 사용할 수 있는지 간단히 확인합니다. 이 단계는 정식 테스트 요청이 아니라 사용 가능성 확인이며, 정식 적합성 테스트는 내용물 확정 후 QC 관련 절차로 진행합니다.

용기 유형주로 사용하는 제품디자인팀 확인사항
막캡토너, 로션박킹 종류, 밀폐 구조, 실제 충전량
일반 펌프토너, 로션, 크림, 샴푸, 트리트먼트펌프 헤드, 스트로우 길이, 잠금 방향
에센스 펌프앰플, 로션1회 토출량과 제형별 배출 차이
튜브폼클렌징, 크림, 마스크파이, 높이, 실링면, 캡 구조
스포이드앰플, 에센스유리/플라스틱 관, 고무 재질, 역류방지캡
자 용기크림, 마스크, 토너패드내용기 유무, 실제 용량, 외관 크기와 단가
비닐 파우치마스크팩 등충전량, 접착·실링, 인쇄 영역

용기 확정 전 간이 확인

선정한 용기에 내용물을 직접 넣어 대략적인 충전량과 사용 상태를 확인합니다.

충전량 확인
100mL 용기라도 내용물 밀도에 따라 100g과 다를 수 있으므로 실제 충전 상태를 확인합니다.
간이 누액 확인
내용물을 넣고 캡이나 펌프를 결합한 후 흔들어 새는 부분이 있는지 봅니다.
사용성 확인
펌프 토출, 스포이드 흡입, 막캡 배출, 튜브 사용감 등을 실제로 확인합니다.
영업·고객사 전달
실제 충전량과 토출량, 용기 특성을 담당자가 이해하도록 안내합니다.

용기별 세부 확인

튜브

25·30·35파이는 기준 높이가 정리되어 있다면 해당 기준을 우선 사용하고, 그 외 규격은 실제 용기를 보고 길이를 별도 확인합니다.

일반 펌프

펌프 헤드 모양을 정하고 스트로우 길이를 확인합니다. 스트로우 길이는 QC팀 또는 디자인팀 내 확인 가능한 담당자에게 문의합니다.

에센스 펌프

제형에 따라 1회 토출량이 달라지므로 실제로 눌러 확인하고 고객사나 영업 담당자에게 설명합니다.

자 용기

내용기가 있으면 외용기를 더 크게 보여줄 수 있지만 단가에 영향을 줍니다. 중국 용기는 표기 용량과 실제 용량이 다른 경우가 있으므로 실물을 기준으로 확인합니다.

스포이드

호환 가능한 여러 스포이드를 준비해 선택받습니다. 유리관과 투명 플라스틱관, 고무 재질, 역류방지캡 여부를 천천히 확인합니다.

막캡

캡형 박킹, 고무 박킹 등 밀폐 부자재가 여러 종류이므로 어떤 박킹이 필요한지 확인합니다.

최종 용기 샘플 및 인쇄 가능 여부

용기가 최종 확정되면 용기 발주 담당자인 신신님에게 최종 용기 샘플을 요청합니다. 실제 생산 예정 사양으로 캡·펌프·박킹·내용기 등 모든 구성품이 포함돼야 합니다.

  • 직접 인쇄 가능 여부 확인
  • 가능하다면 인쇄된 용기 샘플 요청
  • 인쇄 영역 또는 용기 칼선 요청
  • 최종 부자재 조합과 결합 상태 확인

CT 테스트 준비

CT 테스트는 내용물이 최종 확정된 뒤에만 진행합니다.
테스트 용기실제 생산 사양 10개, 모든 결합 부자재 포함
내용물용기 1개 용량의 약 2.5배
예시100mL 용기라면 약 250mL 상당의 최종 내용물
진행용기와 확정 내용물을 공장으로 전달하여 테스트

디자인팀은 테스트에 필요한 용기와 내용물을 준비해 전달하고, 정식 시험 진행과 결과 관리는 QC 관련 절차에 맞춥니다.
