용기·단상자 디자인

패키지 디자인에 필요한 필수 표시자료를 준비하고 용기와 단상자에 정확하게 적용한 뒤 QC 검수 자료를 만듭니다.

업무 설명진행 순서실무 체크리스트
페이지 체크 진행률

이 페이지의 구성

  1. 디자인에 필요한 기본자료
  2. 성분명이 들어가는 경우
  3. 코리안넷 바코드 직접 생성
  4. 용기 분리배출 표시

디자인에 필요한 기본자료

용기와 단상자 디자인은 단순히 앞면 이미지만 만드는 작업이 아닙니다. 제품명, 성분, 사용 방법, 기능성 여부, 분리배출, 바코드 등 생산에 필요한 표시자료를 함께 준비해야 합니다.

내용물 확정 전

연구소 제품기술서와 컨셉 성분으로 디자인 방향, 제품명, 주요 문구와 레이아웃을 잡습니다.

내용물 확정 후

최종 전성분, 사용 방법, 주의사항, 기능성 여부를 반영하여 생산용 디자인을 마감합니다.

제품명 또는 전면 문구에 성분이 들어가는 경우

제품명이나 용기·단상자 전면에 특정 성분명이 들어가면 연구소에 해당 성분의 실제 함량을 요청합니다. 임의로 퍼센트나 ppm을 작성하지 않습니다.

  • 해당 성분이 최종 처방에 포함됐는지
  • 표기 가능한 정확한 성분명
  • 실제 함량
  • 원료 함량인지 유효 성분 함량인지

코리안넷 바코드 직접 생성

바코드가 필요한 제품은 디자인팀에서 코리안넷을 통해 직접 생성합니다. 제품명, 용량, 판매 단위를 정확하게 확인한 뒤 생성하고 단상자 디자인에 적용합니다.

제품명·용량·판매 단위를 확인합니다.
코리안넷에서 해당 제품 바코드를 직접 생성합니다.
바코드 번호와 이미지가 일치하는지 확인합니다.
비율을 변형하지 않고 단상자 칼선에 적용합니다.
접지선·재단선과 충분히 떨어졌는지 확인합니다.

용기 분리배출 표시

용기 디자인에는 용기 몸체, 캡, 펌프, 라벨 등의 재질에 맞는 분리배출 방법을 표시합니다. 재질은 임의로 판단하지 않고 용기 업체 또는 발주 담당자에게 확인합니다.

연구소 문구 적용

사용 방법과 사용 시 주의사항

연구소에서 작성한 내용을 그대로 복사해 적용합니다. 디자인에 맞춘 줄바꿈은 가능하지만 문장을 임의로 축약하거나 새 내용을 추가하지 않습니다.

기능성 여부

일반화장품인지, 미백·주름·자외선 차단 또는 복합 기능성 제품인지 확인합니다. 기능성 관련 문구는 연구소 또는 QC팀이 전달한 기준으로 적용합니다.

용기 디자인 적용 항목

  • 브랜드 로고와 브랜드명
  • 제품명과 제품 라인명
  • 제품 용량
  • 주요 컨셉 성분 또는 문구
  • 필요한 경우 확인된 성분 함량
  • 기능성 관련 문구
  • 분리배출 표시
  • LOT 및 사용기한 마킹 위치
작은 용기는 모든 내용을 넣기 어려울 수 있으므로 용기와 단상자의 표시 항목 구분을 QC팀에 확인합니다.
